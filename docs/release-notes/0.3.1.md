- Fixed: computers from Active Directory could be listed twice in the sidebar. That happened when two providers ended up in the same folder: only one of them was shown, and both listed their computers there. A folder now holds one provider, and Toolbox names the provider that owns a folder when a second one is about to land in it. If your setup already has two in one folder, the hidden one now appears next to the first, with a 2 after its name when both were called the same. Delete it from its context menu if you don't need it.
- A provider's folder now always carries the provider's name. Rename the provider and its folder is renamed with everything inside. **Location** in the provider's settings says which folder it sits in. A folder that was named differently from its provider takes the provider's name the next time the provider is saved.
- The sidebar reopens with the folders you had open; earlier versions started with every folder closed. Folders also stay open when you rename or move them.
- Deleting a provider removes its folder as well when nothing else is in it.
- A refresh that is still running when its provider is renamed, moved or deleted no longer leaves entries behind in the old place.
