- Toolbox now updates itself. It looks for a new version once a day and from **Toolbox ▸ Check for Updates…**, shows what changed, and installs it when you agree. Installing restarts the app, so it asks first when sessions are open. **Toolbox ▸ Check for Updates Automatically** turns the daily look off.
- This is the last version to download by hand: later ones arrive in the app. Keep Toolbox in your Applications folder for that to work.
- An update is installed only if it carries the developer's signature. A check sends the app's version and your Mac's language setting, and nothing about your connections or credentials.
