- Every connection now opens in a tab of its own, named after it, instead of splitting the window: SSH, remote desktop, VNC and file transfer alike. Put sessions side by side when you want to: split a pane (⌘D, ⌘⇧D) and open into the empty half, drop a connection from the sidebar on a pane's edge, or right-click a pane's header and choose **Move to Workspace**. A tab closes when its last session ends or is moved away. Double-click a tab to give it a name of your own; clear the name to go back to the automatic one.
- The sidebar in a new tab carries on where the one you opened it from left off: same filter, same folders open, same place in the list.
- Local terminals: **File ▸ New Local Terminal** (⌘⇧T, or the new toolbar button) opens a shell on your Mac in a tab, with the themes and text size of the SSH terminals. The tab shows the folder you are in and the program that is running. Closing an idle shell asks nothing; one that is running a program names it first.
- ⌘F searches the text of a terminal, including what has scrolled out of view (⌘G and ⌘⇧G for the next and previous match).
- Fixed: with a remote desktop open, ⌘V, ⌘C and other shortcuts did nothing in the sidebar's filter, and the remote desktop received the key instead. Shortcuts now go to a remote desktop only while you are working in it.
